# CadVeiculos

Sistema de cadastro de veículos via terminal em Java, com menu interativo para cadastrar, listar, buscar, editar e remover veículos.

## Funcionalidades

- Cadastrar veículo
- Listar veículos
- Buscar veículo
- Editar veículo
- Remover veículo

## Como rodar

```bash
javac CadVeiculos.java input.java
java CadVeiculos
```
